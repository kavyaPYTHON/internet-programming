# Experiment 06: Cake Ordering System

## Run in VS Code
1. Extract the full ZIP folder.
2. Open this experiment folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — sample data, search/filter, and demo form validation

## Important
This is a runnable **front-end starter**, not a complete production system. It runs without installing Node.js or Python. The sample data is stored in the JavaScript file; the form does not save to a database. Features such as real login, multi-user accounts, server-side storage, email/SMS, maps, QR scanning, and real payment gateways need a backend/API and credentials. For payment-related experiments, do not collect real card details in this demo.
